# hw12PolymorphismTypeScript

TypeScript version of Dylan Cumbajin's Animal Farm Prototype. The project demonstrates:

- Inheritance
- Encapsulation
- Abstract classes
- Polymorphism
- Method overriding

## Project structure

- `src/model/`: `FarmAnimal`, `Chicken`, `Cow`, `Pig`, and `Sheep` classes.
- `src/view/Animal.ts`: object creation and polymorphism demonstration.
- `dist/`: JavaScript files generated by the TypeScript compiler.

## Run the compiled project

```bash
node dist/view/Animal.js
```

## Compile again

```bash
npm install
npm run build
npm start
```

The ZIP does not include `node_modules`.
