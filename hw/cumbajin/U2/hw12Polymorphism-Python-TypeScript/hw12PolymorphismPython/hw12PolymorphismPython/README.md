# hw12PolymorphismPython

Python version of Dylan Cumbajin's Animal Farm Prototype. The project demonstrates:

- Inheritance
- Encapsulation
- Abstract classes
- Polymorphism
- Method overriding

## Project structure

- `model/`: `FarmAnimal`, `Chicken`, `Cow`, `Pig`, and `Sheep` classes.
- `view/animal.py`: creation of objects and polymorphism demonstration.
- `main.py`: program entry point.

## Run

Open a terminal in this folder and execute:

```bash
python main.py
```

No external libraries are required.
