# Project: Eurotoldo Event Management System

# Problem Definition

# Problem:

The problem is the difficulty of coordinating equipment and workers across different events. Staff need to know which equipment is reserved, when it will be collected, and when it will be ready for another rental. They also need to organize the people assigned to each task.

Equipment is not immediately available when an event ends because it still needs to be collected, transported, and checked. Using schedules estimated by staff, the program will help identify overlapping reservations and worker assignments.

# Overview:

The Eurotoldo Event Management System is a proposed application that will help Eurotoldo organize equipment rental and installation services. It will connect reservations, equipment availability, work schedules, equipment movements, quotations, and customer payments.

The system will also record the responsible person and confirmed helpers for each setup and dismantling task. The first version will run in a console; a graphical interface will be added during the second course assessment.

**Client:** Fernando Oña, Eurotoldo, Ecuador.

# Background:

Eurotoldo provides tents, structures, chandeliers, tables, chairs, tablecloths, and decorations for weddings, birthdays, graduations, corporate events, and municipal events in different cities in Ecuador.

These services require coordination before and after each event. Equipment must be prepared, transported, and installed. After the event, it must be collected and checked before it can be used again.

Staff also need to coordinate the people assigned to each job. These activities create a need to organize equipment availability and work schedules together so that each reservation can be planned using the resources required.
