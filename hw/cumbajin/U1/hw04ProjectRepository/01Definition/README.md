# WorkShop: Euroldo Event Management System

# Problem Definition

# Problem:

Eurotoldo needs to keep track of its equipment inventory and the quantities committed to each event. When several events take place on overlapping dates, staff need to know which equipment is reserved, which has already been delivered, and how many units remain available for other reservations.

Without organized information, the company may promise more equipment than it can provide. A system is needed to connect equipment quantities with event dates, check availability, and record actual equipment dispatches and returns.

# Overview:

The project involves developing an application to help Eurotoldo manage its equipment inventory and event reservations. It will organize customer information, events, equipment categories, and the quantities assigned to each reservation.

The application will allow staff to consult scheduled events through a calendar and check equipment availability for the requested dates. It will also record full or partial returns and identify equipment that is unavailable due to damage or maintenance.

The first version will run in a console, allowing staff to consult events by date. A graphical interface with a calendar will be added during the second course assessment.

# Background:

Eurotoldo is a company in Ecuador that rents tents, structures, chandeliers, tables, chairs, tablecloths, and decorations for weddings, birthdays, graduations, corporate events, and municipal events.

Each event uses part of the company's inventory. When several events overlap, the available quantities must be distributed among reservations to avoid shortages.

Equipment availability also changes when items leave the company or are returned. Keeping these records organized will help staff identify outstanding returns, track equipment condition, and determine which quantities can be offered for other events.
