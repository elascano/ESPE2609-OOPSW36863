# **Requirements**



## **Functional Requirements.**



**RF - 01:** The system shall allow registering, consulting, and updating client information. 

**RF - 02:** The system shall allow registering, consulting, and updating equipment, including name, category, and total quantity available for rental.

**RF - 03:** The system shall allow registering events, including event type, location, event dates, setup date and time, and expected removal date and time. 

**RF - 04:** The system shall allow registering a quotation with the requested equipment, their quantities, and the agreed value. 

**RF - 05:** The system shall allow creating, consulting, updating, and canceling reservations associated with a client and an event. 

**RF - 06:** The system shall allow assigning equipment and quantities to each reservation, verifying availability. 

**RF - 07:** The system shall allow registering and updating setup and removal schedules, as well marking each activity as completed. 

**RF - 08:** The system shall allow registering payments made for each reservation and calculating the outstanding balance. 

**RF - 09:** The system shall display a summary of each reservation with client data, event details, assigned equipment, setup, removal, total value, registered payments, and outstanding balance. 

## 

## **Non - Functional Requirements.** 



**RNF - 01:** The system shall preserve registered information and allow consulting it after closing and reopening the program. 

**RNF - 02:** The system shall restrict access to client and payment information to authorized users. 

**RNF - 03:** The system shall display dates, monetary values, and reservation statuses in a uniform format. 

**RNF - 04:** The system shall use clear labels and messages so that business staff can identify and perform their main operations.
